# Data

This repository does not redistribute the two raw input files. Both are
freely available from the original sources and must be placed in the
repository root before running any of the three scripts.

## `Rates_BA_1.zip` — ECB Survey of Professional Forecasters (SPF)

Individual point-forecast microdata, current-year, one-year-ahead and
two-year-ahead HICP inflation, all survey rounds.

Source: European Central Bank, Survey of Professional Forecasters.
<https://www.ecb.europa.eu/stats/ecb_surveys/survey_of_professional_forecasters/html/index.en.html>

Download the "Inflation expectations" individual-forecaster dataset and
save it as `Rates_BA_1.zip` in the repository root.

## `Rates_BA_2_csv.gz` — Eurostat realised HICP inflation

Realised annual HICP inflation, euro area of changing composition, annual
average rate of change.

Source: Eurostat, dataset `prc_hicp_aind`.
<https://ec.europa.eu/eurostat/databrowser/view/prc_hicp_aind>

Export the series as CSV, compress it, and save it as `Rates_BA_2_csv.gz`
in the repository root.

Both sources were retrieved in August 2026; see the References section of
the thesis for the full citations.
